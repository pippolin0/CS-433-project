## Data
The data is too heavy to be placed inside the repository. Instead, 
1. Go to https://www.aicrowd.com/challenges/epfl-machine-learning-project-1/dataset_files and download the dataset.
2. Put the 4 files, namely `x_train.csv`, `y_train.csv`, `x_test.csv`, `sample-submission.csv` into a __folder called `data`__.  
Since the `data/`folder is already handled by the `.gitignore`, there is no need to do anything anymore, subsequent git commands will not add your local `data` folder into the repository.  
Note that it is important to keep the folder and file names as is!
3. Start playing with the dataset!
